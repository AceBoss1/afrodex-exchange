## **Step-by-Step Implementation**

### **Step 1: Setup Project**
```bash
cd your-afrodex-project
npm init -y
mkdir -p app components lib/abi public styles
```

### **Step 2: Install All Dependencies**
```bash
npm install react react-dom next
npm install wagmi viem @rainbow-me/rainbowkit @tanstack/react-query
npm install lucide-react
npm install -D tailwindcss postcss autoprefixer typescript @types/react @types/node
```

### **Step 3: Copy Files from Artifacts**

#### **A) `app/layout.tsx`**
```bash
# Create the file and paste artifact code
touch app/layout.tsx
```

#### **B) `app/page.tsx`**
```bash
touch app/page.tsx
```

#### **C) `components/AfroDexPlatform.jsx`** ⭐
```bash

touch components/AfroDexPlatform.jsx
```

```bash
touch lib/contractClient.js
```


### **Step 5: Add Environment Variables**

**`.env.local` (CREATE THIS FILE)**
```env
# Alchemy API (get from https://www.alchemy.com)
NEXT_PUBLIC_ALCHEMY_KEY=your_alchemy_api_key_here

# WalletConnect Project ID (get from https://cloud.walletconnect.com)
NEXT_PUBLIC_WC_PROJECT_ID=your_walletconnect_project_id

# Contract Address (Do NOT change)
NEXT_PUBLIC_CONTRACT_ADDRESS=0xe8fff15bb5e14095bfdfa8bb85d83cc900c23c56

# Chain ID (Ethereum Mainnet)
NEXT_PUBLIC_CHAIN_ID=1

# Optional
NEXT_PUBLIC_RPC_URL=https://eth-mainnet.g.alchemy.com/v2/your_alchemy_api_key_here
```

## **Troubleshooting**

### ❌ "Connect Wallet" Not Working
- Ensure MetaMask is installed
- Check `NEXT_PUBLIC_WC_PROJECT_ID` is set
- Clear browser cache

### ❌ Transaction Failing
- Check you have ETH for gas
- Verify RPC URL is correct
- Check contract address: `0xe8fff15bb5e14095bfdfa8bb85d83cc900c23c56`

### ❌ Balance Not Updating
- Refresh page
- Check wallet is connected
- Verify RPC URL in `.env.local`

### ❌ Build Error
```bash
# Clear cache and rebuild
rm -rf .next
npm run build
```
